# Project instructions

- Responda em português brasileiro em todas as interações relacionadas a este projeto.
- Use português brasileiro em todos os dados enviados ao banco de dados, incluindo textos de exemplo, descrições, nomes de responsáveis e mensagens visíveis ao usuário.
- Para commits, utilize a estrutura Conventional Commits com descrição em português, por exemplo: `feat: adição da autenticação com o banco de dados firebase`.
